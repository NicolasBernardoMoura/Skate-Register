# 🛹 Skate Cadastro

Sistema web desenvolvido com Django para cadastro e gerenciamento de skatistas.

## Funcionalidades

- Cadastro de skatistas
- Banco de dados integrado
- Interface responsiva
- Painel administrativo do Django
- Upload de imagens

## Tecnologias

- Python
- Django
- HTML
- CSS
- SQLite

## Como executar

Clone o projeto:

```bash
git clone https://github.com/NicolasBernardoMoura/skate-register.git
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute as migrações:

```bash
python manage.py migrate
```

Inicie o servidor:

```bash
python manage.py runserver
```
